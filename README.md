# Асистент — MVP (модуль 1: посилання + чат з ШІ)

## Що вже працює
- Кидаєш будь-яке посилання (Instagram, TikTok, будь-яке інше) — бот сам пропонує категорію (Одяг / Фільми / Прикраси / Заклади / Інше), ти підтверджуєш кнопкою або обираєш іншу
- `/links` — показати останні 20 збережених посилань
- `/links Одяг` — показати посилання тільки з категорії "Одяг"
- Будь-який звичайний текст (не посилання) — бот відповідає як універсальний чат через Gemini

## Як запустити локально (для перевірки, поки нема хостингу)

1. Встанови Python 3.11+ якщо ще нема
2. Відкрий термінал у папці проєкту і виконай:

```
pip install -r requirements.txt
python bot.py
```

3. Знайди свого бота в Telegram (за іменем, яке дав @BotFather) і напиши `/start`

Бот працюватиме, поки термінал відкритий і скрипт запущений. Коли підключимо хостинг (Railway) — він працюватиме постійно, без ноутбука.

## Структура проєкту

- `bot.py` — головний файл, обробка повідомлень
- `database.py` — база даних (SQLite, файл `assistant.db` створюється автоматично)
- `ai.py` — звʼязок з Gemini
- `.env` — токен бота і ключ Gemini (не показуй нікому цей файл)
